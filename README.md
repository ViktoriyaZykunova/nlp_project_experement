# Генеративные методы: влияние temperature, top‑p, top‑k на разнообразие текстов

## Описание проекта
Данный проект исследует, как гиперпараметры языковой модели (temperature, top‑p, top‑k) влияют на лексическое и структурное разнообразие текстов, сгенерированных GPT‑4o‑mini. Рассматриваются три жанра/типа: новости, поэзия и научный текст.

## Основные результаты
- Температура **не оказывает статистически значимого влияния** на TTR (p > 0.9), но сильно влияет на self‑BLEU.
- Увеличение top_k незначительно повышает разнообразие и снижает повторяемость слов.
- Поэзия демонстрирует максимальную вариативность при высокой температуре, а научный стиль – склонность к шаблонности.
- Разработан **интерактивный виджет** для тестирования параметров в реальном времени.
